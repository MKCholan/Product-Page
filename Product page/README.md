# Product Splash Page

A responsive product splash page built as part of the Scrimba Fullstack Developer Path. This project is a promotional landing page for a fictional "Scrimbafy" avatar generation tool, featuring fluid typography, flexible layouts, and a responsive sign-up form.

## 🚀 Technologies Used
* HTML5
* CSS3

## 🎯 Key Concepts & Learnings
This project focuses on modern CSS layout and styling techniques:
* **Fluid Typography & Containers:** Utilizing CSS viewport units to create responsive text and layout containers that naturally adapt to different screen sizes.
* **Flexbox Reordering:** Using the flexbox `order` property to change the visual layout of content independently of the semantic HTML document flow.
* **Predictable Layouts:** Implementing a global `box-sizing: border-box` reset (including `::before` and `::after` pseudo-elements) to ensure padding and borders do not unexpectedly expand element dimensions.
* **Text Manipulation:** Applying the CSS `text-transform` property to control text case and capitalization strictly through stylesheets.
* **Form Styling:** Designing responsive, user-friendly form inputs for name and email data collection.
* **CSS Architecture:** Writing clean, reusable modifier classes for scalable styling.

## 📁 Project Structure
* `index.html` - The main HTML document containing the semantic structure and form.
* `styles.css` - The primary stylesheet containing layout rules, responsive media queries, and typography styling.
* `images/` - Directory containing the project's image assets (`avatar.png` and `intro-bg.png`).

## 🛠️ How to Run
1. Clone this repository to your local machine.
2. Open the project folder.
3. Launch `index.html` in your preferred web browser, or use a tool like VS Code Live Server to view the page. No package installation or build steps are required.
